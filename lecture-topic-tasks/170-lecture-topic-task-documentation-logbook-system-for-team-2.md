## Details
🎯 Objective
Create a Documentation Logbook System to record and track project milestones, key decisions, and acceptance notes ensuring the team’s documentation remains organized, transparent, and traceable.

📝 Description
We need to establish a centralized digital logbook that serves as a living record of project progress.
The logbook should include columns for:

- Date – When the event or decision occurred
- Decision / Event – Description of what happened 
- Responsible – Team member(s) accountable
- Impact – Effect on project scope, schedule, or deliverables


✅ Acceptance Criteria

- Columns include Date, Decision, Responsible, Impact,
-  Entries are formatted consistently and timestamped
-  Logbook is reviewed by team lead 
-  Documented decisions align with team’s documentation standards
- Accessible to all team members

🧪 Testing Plan
Review the entries with the team to confirm accuracy
Ensure Milestone #2 is documented
