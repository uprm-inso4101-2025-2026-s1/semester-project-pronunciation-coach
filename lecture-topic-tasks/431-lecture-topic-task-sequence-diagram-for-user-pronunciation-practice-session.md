## 🎯 Objective
Use the *Sequence Diagrams* lecture to model the interaction when a user practices a phrase and receives automatic feedback in the Pronunciation Coach App.

---

## 📝 Description
Create a sequence diagram that shows how the app handles a pronunciation attempt using the concepts from the Sequence Diagrams lecture. The diagram will include the User, PracticeScreen, RecorderService, FeedbackEngine, STTService, and FeedbackView, and will illustrate the flow from starting the recording to generating and displaying feedback. The final diagram will be added to `docs/diagrams/` and referenced in the documentation.

- [ ] Messages show: `startRecording`, `stopRecording`, `analyzeAudio`, `requestSTT`, `buildFeedback`, `displayFeedback`.
