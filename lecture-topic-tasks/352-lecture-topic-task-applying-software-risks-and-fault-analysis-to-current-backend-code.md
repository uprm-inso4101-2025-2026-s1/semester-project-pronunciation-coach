## 🎯 Objective

Identify, analyze, and document potential software risks in the current project by applying concepts from the lecture topic on software errors, fault types, and risk assessment. Produce a PDF report summarizing the findings.

---

## 📝 Description

This task involves performing a structured analysis of the project’s existing architecture, Dart/Flutter codebase, and backend  through the lens of the concepts presented in slide03.pdf 

The goal is to identify:
- Possible areas where faults may occur.
- Risks caused by architectural decisions.
- Failure scenarios and how they could affect the system.
- Mitigation strategies grounded in lecture concepts.

The end result will be a research PDF detailing analysis, examples, and proposed improvements.
