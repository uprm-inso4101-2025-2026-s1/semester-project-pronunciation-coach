## Details
## 🎯 Objective
Build a Recent Activity Timeline that displays the user’s last ten quiz results.

This is a lecture topic / learning feedback feature because it provides instant visual feedback to the user: instead of just raw numbers or lists, they can see a timeline of progress, which makes learning outcomes more visual, turning raw performance data into instant, intuitive visual feedback. 

---

## 📝 Description  
We need to implement a component on the **Dashboard** that visualizes the user’s most recent quizzes.  

**Requirements:**  
- Display up to **10 recent quiz results**.  
- Each entry should include:  
   - Green checkmark box for correct / passed quizzes
   - Red X box for incorrect / failed quizzes

---

## ✅ Acceptance Criteria  
- [ ] Displays the **last 10 quiz results** in order.  
- [ ] Handles the case when there is **no activity yet** (shows placeholder or message).  

---

## 🧪 Testing Plan
- Timeline correctly shows 10 items maximum.  
- Empty-state message appears when there’s no activity.
