## 🎯 Objective
Apply requirements evaluation to our finished feature to check how we avoided inconsistencies, overlaps, and conflicts. Document how the work was split across team members so no one coded something that already existed.

## 📝 Description
Using the lecture topic “Requirements engineering”, we will review the code that’s already implemented (quiz feature).

The task is to:

Analyze how responsibilities were divided among team members to avoid duplicate or conflicting implementations.

Summarize concrete practices we followed (or should follow next time) to reduce inconsistencies and missing requirements.
