## Details
## 🎯 Objective
Analyze existing quiz code as a concrete case study to distinguish between phenomena and concepts. The goal is for students to learn how to move back and forth between concrete code/behavior and the underlying abstract ideas it implements.

---

## 📝 Description
In this lecture task, we use the existing quiz code as a case study to practice separating phenomena from concepts. Students will look at concrete behaviors in a running quiz (questions shown, answers chosen, scores updated) and label these as phenomena, then inspect the code (classes, data structures, functions, abstractions) and label those as concepts. Each student will produce a brief mapping that links specific phenomena in the quiz to the concepts that generate or explain them.

## ✅ Acceptance Criteria
List the conditions that must be met for this issue to be considered complete.

- [ ] Instructor reviews a sample of student artifacts and confirms that phenomena and concepts are correctly distinguished and labeled.

## 🧪 Testing Plan
How will this be tested?

Each phenomenon is mapped to a reasonable concept from the quiz.
