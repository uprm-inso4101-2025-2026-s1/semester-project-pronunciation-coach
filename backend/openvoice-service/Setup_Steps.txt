-------------------------------------------------------------
                    OpenVoice API Set-Up
-------------------------------------------------------------

To activate the FastAPI and make use of OpenVoice's Text-to-Speech:

    1. Run the command cd backend/openvoice_service/OpenVoice 

    2. Follow the instructions from issue #210 (Implementing and 
       testing OpenVoice for voice cloning) to set up a virtual environment
       for OpenVoice
       - Make sure to setup venv using Python 3.9 or 3.10

    3. Once the virtual environment is active, run:
       pip install fastapi

    4. To activate the API host, run the command:
       uvicorn openvoice_api:app --host 0.0.0.0 --port 5001 --reload

    5. Once the API is active, open a new terminal (without closing the
       current one) and run the app as normal. For Voice Cloning to work,
       the API needs to be hosted.

    NOTE: Voice-Cloning feature only works on desktop when running on desktop.
